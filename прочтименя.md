# AltBot

[English](README.md) | **Русский**

![AltBot: the stats board and the action bar](altbot.png)

AltBot - аддон для World of Warcraft **3.3.5a (WotLK)** для игры с ботами
[mod-playerbots](https://github.com/liyunfan1223/mod-playerbots) на сервере AzerothCore.

Большинство аддонов для playerbots заточено под **прохождение рейдов с дикими (случайными) ботами**. AltBot сделан для другого:
для **квестинга и прокачки с собственными альтботами** - вашими собственными твинками на аккаунте, которыми играет ИИ ботов,
пока вы ими руководите. Один персонаж, *мастер*, ведёт их; аддон даёт табло со статистикой, панель действий и набор окон по
каждому боту (сумки, армори, стратегии, квесты, книга заклинаний) и сам собирает рейд, опрашивает ботов, сбрасывает их
сумки, поднимает мёртвых и так далее. Это заметно по устройству: квестлог сравнивает квесты всей команды, армори и сумки
позволяют ухаживать за каждым альтботом отдельно, Farm-режим занимает прокачивающуюся команду сам. С дикими ботами всё
тоже прекрасно работает: впишите слово-класс в ростер, и аддон наберёт и будет отслеживать их как любых других (просто их
данные не сохраняются между сеансами).

Всё идёт через обычные **шёпоты и чат группы**: менять сервер и ставить дополнительные аддоны-мосты не нужно. Если команда
работает, когда вы пишете её боту вручную, аддон тоже может её отправить.

## Требования

- Клиент WotLK 3.3.5a и сервер AzerothCore с **mod-playerbots**. Мастеру должны быть разрешены команды
  `.playerbots bot add / remove / addclass` (аддон отправляет их в `/s`).
- Боты должны отвечать на обычные шёпоты (`stats`, `items`, `who`, `spells`, `quests all`, `co ?`, `nc ?` ...) - так mod-playerbots
  работает по умолчанию.
- По желанию: **GearScoreLite** (тогда окно армори показывает тот же GearScore, что и родное окно).

## Установка

Скопируйте папку `AltBot` в `World of Warcraft/Interface/AddOns/` так, чтобы существовал файл
`Interface/AddOns/AltBot/AltBot.toc`, и перезапустите клиент (или включите аддон на экране выбора персонажа). Таблицы заклинаний,
квестов и зон встроены в `AltBot.lua`; зависимостей у аддона нет.

## Быстрый старт

1. Зайдите мастером. У миникарты появится маленькая иконка AltBot; **клик по ней** показывает или скрывает табло вместе с панелью
   действий.
2. На панели нажмите кнопку **Roster** (иконка приручения зверя). Впишите имена ботов через пробел и нажмите **Save**:
   - `Kora Nora Xora` - три именованных бота;
   - слово-класс, английское или русское (`warlock`, `dk`, `воин`, `жрец`, `дк`...), просит у сервера одного *дикого* бота этого
     класса (`.playerbots bot addclass`); два таких слова - два бота;
   - своё имя можно тоже написать, оно просто игнорируется;
   - слово, начинающееся с `-`, считается комментарием и пропускается.
3. Выберите режим кнопками **Quest Mode**, **Farm Mode** или **Solo Mode** (см. [Режимы](#режимы)). Аддон пригласит ботов,
   преобразует группу в рейд, когда это возможно, и выведет одну строку, например `Quest mode, 8 bot(s).`
4. Когда рейд собран, появляется табло: по одной рамке на группу рейда, по одной колонке на участника.

Для рейда нужен мастер и хотя бы один бот уровня 10 и выше (правило сервера); ниже этого получится обычная группа до 5 человек.

## Панель действий

Слева направо (первые шесть кнопок есть только в Quest-режиме):

| Кнопка | Что делает |
| --- | --- |
| Attack | группа атакует вашу текущую цель |
| Follow / Stay | все боты идут за вами / стоят на месте |
| Aggressive / Defensive / Passive | боевая реакция ботов |
| **Quest Mode** | призвать ростер, он следует за вами |
| **Farm Mode** | боты бродят и гриндят сами |
| **Solo Mode** | распустить: убрать всех ботов, вы играете один |
| Roster | открыть окно ростера |
| Шестерёнка | открыть настройки AltBot |
| пустая иконка с рифлёным краем | за неё перетаскивается панель |

Follow/Stay, реакция и режим **общие для аккаунта**: что выставил один мастер, с тем и зайдёт следующий, а рейд приводится в это
состояние после того, как собран.

## Режимы

- **Solo** - ростер убран из мира, ничего не опрашивается, табло скрыто. Режим запоминается, поэтому следующий персонаж
  аккаунта тоже стартует в Solo.
- **Quest** - боты идут за вами. Аддон держит ростер в группе, сбрасывает стратегии всех ботов до умолчаний и применяет ваши
  сохранённые Follow/Stay и Aggressive/Defensive/Passive.
- **Farm** - боты гриндят сами (`nc +new rpg,-follow`). Каждые 30 с у каждого бота запрашиваются `stats` и `rpg status`; бот,
  который не гриндит, получает команду гринда заново. Бот с **полными сумками** призывается, продаёт (`s *`, а если включено
  *sell vendor*, то `s vendor`) и снова отправляется бродить; **мёртвого** бота поднимает призыв. Клик по верхней строке колонки
  бота (строке с приростом опыта за час, например `+2%`) **паркует** его рядом с вами (призыв, сброс, продажа), повторный клик возвращает его к работе.

## Табло

Отдельная перетаскиваемая рамка на каждую **группу рейда** (для обычной группы одна рамка). Показывается только после того,
как рейд собран. Мастер тоже колонка, на том месте, которое ему даёт состав рейда. В колонке сверху вниз: опыт, набранный
**за этот час**, иконка класса, имя, свободно/всего слотов сумок, золото, % опыта и уровень. Тонкая серая полоска внизу
горит, пока ждётся ответ `stats` этого бота. Данные сохраняются, поэтому после `/reload` табло сразу заполнено; «дикие» боты
не сохраняются и показывают `?` до первого ответа.

| Клик по... | Бот | Мастер |
| --- | --- | --- |
| иконка класса | окно армори | окно персонажа |
| имя | окно стратегий | стратегии **всей группы** |
| строка сумок | окно сумок | все сумки |
| % опыта | окно квестлога | родной журнал заданий |
| уровень | книга заклинаний | родная книга заклинаний |
| верхняя строка с приростом опыта за час `+N%` (Farm) | припарковать / вернуть бота | - |

**Перенос между группами:** перетащите колонку за **иконку класса** на рамку другой группы. Если там есть свободное место,
участник переходит туда; если группа полная, бросьте на участника - они поменяются местами. (Нужны права лидера или
ассистента рейда.) Пока вы тащите, первая пустая группа предлагается как цель.

## Окна ботов

Все они независимы, помнят свою позицию для каждого бота и открываются сразу из сохранённых данных, пока идёт свежий запрос.
Shift-клик по предмету, заклинанию или квесту вставляет ссылку в чат.

- **Армори** - родная по виду кукла, собранная из запросов по слотам (`who` и по запросу на слот, около 20 шёпотов), с
  моделью, GearScore, iLevel, спеком и талантами. Закрытие во время запроса «фиктивное»: окно становится невидимым и по-
  настоящему закрывается, когда ответ на последний запрос получен, чтобы окно обмена, которое открывает бот, по-прежнему
  подавлялось. Работает **на любом расстоянии**: бот не обязан быть рядом с вами (и даже в поле зрения), потому что всё читается
  из его ответов в чате, а не инспектированием. Только 3D-модели нужно один раз за сеанс увидеть бота.
- **Сумки** - инвентарь бота по ответу `items`. Левый клик выполняет действие, выбранное в подвале (*Sell* или *Trade*, клик по
  левой или правой половине), правый клик открывает меню. Окно поддерживает **продажу** (торговцу, у которого стоит бот),
  **обмен** (предмет переходит к вам через окно обмена), **сдачу в гильдейский банк** и **уничтожение**, плюс ссылку на
  Wowhead; предметы можно перетаскивать для сортировки. Свободные слоты берутся из `stats`.
- **Стратегии** - формы боя и вне боя в стиле CleanBot (выпадающие списки, галки, ползунок задержки); изменения отправляются как
  `co ...` / `nc ...`, окно следует и за командами, набранными вручную. Клик по имени **мастера** открывает ту же форму для
  **всей группы**: каждое изменение уходит всем ботам (список Role там недоступен; галка, включённая только у части ботов,
  белая со звёздочкой). Список **Find** (None / Herb / Ore) держит включённым отслеживание «Поиск трав / Поиск минералов».
- **Квестлог** - невыполненные квесты **по зонам**, выполненные внизу. Колонки: id квеста, `[N]` (сколько участников рейда, боты
  и мастер, имеют этот квест), ссылка на квест и его русское название. Правый клик **бросает** квест у этого бота. Родной
  журнал заданий мастера показывает такое же число `[N]` по всему рейду вместо числа по группе.
- **Книга заклинаний** - заклинания бота в пяти группах: три ветки талантов (английское и русское название),
  *Professions* и *Other*. Левый клик заставляет бота скастовать заклинание, правый создаёт макрос `/w <бот> cast <заклинание>` и
  кладёт его на курсор, чтобы вы бросили его на панель и применили в нужный момент боя.

## Настройки и управление чатом

Нажмите шестерёнку на панели. Вверху небольшой график показывает, сколько памяти занимает сам аддон (замер раз в 5 минут,
один столбик на час со средним за час). Ниже галки:

- **sell vendor** - продавать командой `s vendor` вместо `s *`.
- **chat init / stats / farm / inventory / armory / strategies / questlog / spellbook** - по умолчанию в чат **ничего** из
  того, что делает аддон, не попадает. Включите нужную область, чтобы смотреть только её: команды, ответы ботов и сообщения
  самого аддона. `init` забирает и всё, что не подошло другой области (загрузка, сбор группы, смена режимов, ошибки). Всегда
  видны только *строка режима* и **тревоги** о припасах (охотник без боеприпасов, разбойник без ядов - красным по жёлтому).
  Ваши собственные шёпоты и чат никогда не скрываются.
- **dance** - в Quest-режиме группе каждые 10 с отправляется `emote dance`; мастер объявляет это в `/s`.
- **emotes** - в Quest-режиме раз в 5 минут один случайный бот делает случайную анимированную эмоцию.
- **delete cache** - аддон каждый раз стартует как в самый первый раз (все сохранённые данные стираются). Для отладки.

## Торговцы

- Когда вы открываете окно торговца, **каждый отслеживаемый бот** получает команду продажи хлама (`s *` / `s vendor`); продают
  те, кто стоит рядом с этим торговцем, остальным продавать некому.
- В **Quest-режиме, если бот в вашей цели**, предмет, по которому вы кликнули у торговца, покупается **для этого бота** (ему
  шёпотом уходит `b <ссылка>`, по разу на каждый лот, со звоном монет): его золото и количество предмета обновляются сразу,
  а реальное число слотов приходит со следующим `stats`. Без бота в цели покупка обычная, ваша.

## Слэш-команды

Только две диагностические: `/abfocus` (потом за 4 секунды наведите мышь на элемент интерфейса - выведет фрейм под курсором) и
`/abglobals Префикс` (список глобальных таблиц, имена которых начинаются с префикса).

## Сохраняемые данные

`AltBot_SavedVars` (общий для аккаунта): текст ростера, режим, follow/stay и реакция, позиции окон и табло, настройки и кэши
(сумки, экипировка, `who`, списки квестов и заклинаний, последние числа табло, почасовой опыт). Кэши **диких** ботов
стираются при выходе. График памяти не сохраняется.

## Ограничения

- Аддон сделан под конфигурацию одного сервера. На нём отключены стратегии `grind` и `aggressive`, поэтому боты сражаются
  только с тем, что нападает на них при блуждании; прицельный фарм (шкуры, выбор моба) и приведение бота к узлу сбора
  **невозможны**. Узел бот собирает, только если пробегает вплотную.
- Часть команд написана так, как их принимают сборки mod-playerbots 3.3.5 (`b <ссылка>` для покупки, `emote <имя>`, `quests all`,
  `spells`). На другой сборке написание может отличаться - тогда соответствующая функция просто ничего не делает.
- Вне игры аддон проверяется только на синтаксис; в клиенте его проверял автор.

## Разработка

`AltBot.lua` - один большой файл; его главный чанк близок к пределу Lua 5.1 в 200 локальных переменных, поэтому новые
помощники вешаются на таблицу `NS`. Используются проверки `luac -p AltBot.lua` и языковой сервер Lua (`.luarc.json`, заглушки
API в `wow-stubs/wow-api.lua`). Встроенные таблицы данных генерируются отдельно из перечисленных ниже источников (скрипты
генерации в этот репозиторий не входят). `playerbot.txt` - русский перевод конфигурационного файла mod-playerbots, для справки.

## Источники данных

- Таблицы заклинаний и веток талантов: Wowhead (WotLK Classic).
- Названия и зоны квестов: сгенерированы из данных собственного аддона автора QuestChromeCraft.
- Названия зон и их русские переводы: таблицы аддона Questie.
- Окно стратегий повторяет раскладку панели стратегий CleanBot.
